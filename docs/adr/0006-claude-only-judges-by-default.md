# Rubric Graders use Claude only by default

The only LLM available at no extra cost is Claude, through the Claude subscription. Other model families are reachable only through paid APIs. By default, Rubric Graders therefore use Claude judges only, even though the research recommends a panel from several model families to counter self-preference bias, which matters most when Claude is judging Claude-produced work. This bias is accepted and recorded in every report that relies on a Rubric Grader. A multi-family panel stays an opt-in for Runs where the extra API cost is justified.
