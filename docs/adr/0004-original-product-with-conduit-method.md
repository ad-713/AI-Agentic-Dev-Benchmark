# An original product, not RealWorld/Conduit, built with Conduit's method

The benchmark app is an original product. It is not RealWorld/Conduit, even though Conduit ships ready-made API and E2E acceptance tests and was the research's first recommendation. Conduit and its many implementations sit in model training data. A Workflow could therefore recite it instead of defining it, and the definition phase (PRD, Spec) is exactly what we most want to evaluate. We do reuse Conduit's method: an OpenAPI contract, API tests in Hurl, and Playwright E2E tests driven by a UI selector contract.
